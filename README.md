Модель OSI — это универсальная инструкция из 7 уровней, которая объясняет, как компьютеры передают данные друг другу по сети. Главная цель: сделать так, чтобы техника и программы от разных производителей могли понимать друг друга.
7 уровней (снизу вверх: от «железа» к программам)
Физический (Кабели и сигналы) передает нули и единицы по проводам или через воздух. Пример: Витая пара, оптоволокно, Wi-Fi-сигнал, USB.
Канальный (MAC-адреса) объединяет биты в «кадры» и доставляет их между соседними устройствами в одной локальной сети. Пример: MAC-адрес, Ethernet, коммутатор (свитч).
Сетевой (IP-адреса и маршруты) определяет лучший путь доставки данных из одной сети в другую через весь интернет. Пример: IP-адрес, роутер (маршрутизатор), протокол IP.
Транспортный (Надежная доставка) разбивает данные на части, нумерует их и контролирует, чтобы всё дошло целым и без ошибок. Пример: Протоколы TCP и UDP 
Сеансовый (Управление связью) устанавливает, поддерживает и корректно завершает соединение между двумя программами. Пример: Как телефонный звонок: набрать номер, поговорить, повесить трубку.
Представительский (Формат и шифрование) приводит данные к понятному виду: шифрует, сжимает, переводит в нужный формат (чтобы получатель мог это открыть). Пример: Форматы JPEG, MP3, шифрование (SSL/TLS).
Прикладной (Интерфейс для пользователя) предоставляет сетевые услуги непосредственно вашим программам. Это единственный уровень, с которым взаимодействует человек. Пример: Браузер (HTTP/HTTPS), электронная почта (SMTP), мессенджеры.
